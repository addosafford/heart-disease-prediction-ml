# heart-disease-prediction-ml
Heart Disease Prediction using Random Forest Machine Learning Algorithm

# Project Description
This project uses Machine Learning to predict heart disease using patient medical data.

# Algorithm Used
Random Forest Classifier

# Dataset
Heart Disease Dataset from Kaggle

# Technologies Used
- Python
- Jupyter Notebook
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

# Model Evaluation
The Model was evaluated using:
- Accuracy
- Confusion Matrix
- Precision
- Recall
- F1-score
